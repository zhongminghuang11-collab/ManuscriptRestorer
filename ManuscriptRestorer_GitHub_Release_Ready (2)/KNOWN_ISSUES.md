# 已知缺陷与限制 / Known issues

**状态：实验性原型，不建议无人监督地处理真实档案。**

更新：2026-11-22。以下项目保留未解决状态，不能以现有单元测试通过来替代实际手写数据验证。

|---|---|---|---|---|

## 已观察到的 OCR 异常

在合成示例图上的一次 Tesseract 识别中，`晚上还要开会。` 未被正确转写，末尾出现非中文乱码。这表明即使在合成图片上，OCR 输出也需要人工核对。该观察不是正式准确率测量，不能据此推断真实手写识别的平均表现。

## 验收基准建议

发布下一稳定版本前至少需要：

1. 经授权且脱敏的真实修改手稿，单独保留训练/开发/测试集。
2. 原文、终稿、修改操作、笔迹框位置的人工标准答案。
3. 与 Tesseract、PaddleOCR 和人工校对基线的统一比较。
4. 字符错误率（CER）、修改事件 F1、人工完成时间、误确认率等数据。
5. 对失败样本公开报告，而非只展示成功案例。

## 风险说明

任何“划除候选”或视觉模型的建议都不应自动确认为最终编辑结果。对于不可辨认文字，输出“不确定”通常比猜测更安全。
