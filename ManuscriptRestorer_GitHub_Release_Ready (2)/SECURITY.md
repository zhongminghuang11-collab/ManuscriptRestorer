# Security and privacy

The service is intended to run on the local machine, bound to `127.0.0.1` by default. Do not expose it to the public internet without a separate security assessment.

Projects may contain complete images of handwritten pages. Do not commit real manuscripts, exported JSON projects, personal information, credentials, or private model configurations. Keep all suggestions unconfirmed until a human verifies them.

Downloaded OCR/vision models and system dependencies have independent provenance and license obligations. Updating or adding a dependency requires an appropriate security review.

## 公共仓库安全建议

请勿在公开 issue 或 Pull Request 中附上尚未脱敏的实际手稿。涉及潜在漏洞时，优先使用 GitHub 私下漏洞报告（如维护者开启该功能），或先联系仓库维护者确认安全通道。
